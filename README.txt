憲法小達人｜知識冒險島
========================

使用方法：
1. 直接在 iPad Safari 開啟 index.html（建議使用網站網址）。
2. 選擇初級或進階；每關隨機抽取一題，全部答對才獲獎。
3. 每次完成後按「下一位參加者」。

部署 GitHub Pages：
1. 在 GitHub 新建一個 Public repository，例如 constitution-adventure。
2. 上載 index.html 到儲存庫根目錄。
3. Settings → Pages → Build and deployment → Deploy from a branch。
4. 選擇 main / (root)，按 Save。
5. 等候網站發佈後，開啟 https://你的帳號.github.io/constitution-adventure/

題庫：初級 2 關各 10 題；進階 3 關各 10 題，共 50 題。
每關每位學生只答 1 題；各裝置在題庫用完前盡量不重複抽題。

注意：
- 全部資料和圖案均內置於 index.html，不需要額外下載素材。
- 國旗使用系統 emoji，國徽及區徽採文字情境提示而非官方圖像；正式攤位使用前可換上經核實的官方素材。
- 請先用學校的 iPad 進行試玩，確認題目難度、答題時間及操作流程。
